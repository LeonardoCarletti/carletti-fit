# diabeticoimortal.fit

Landing page e loja de produtos digitais da **Carletti Fit / Diabético Imortal**.

Site em produção: [diabeticoimortal.fit](https://diabeticoimortal.fit)

## Stack

- Vite + React + TypeScript
- Tailwind CSS
- React Router
- Deploy: Vercel

## Desenvolvimento

```bash
npm install
npm run dev
```

## Rotas

| Rota | Descrição |
|---|---|
| `/` | Landing page |
| `/loja` | Catálogo de produtos |
| `/loja/ferramentas/calculadora-carga-glicemica` | Calculadora CG |
| `/loja/ferramentas/guia-marcas-expandido` | Guia de marcas |
| `/loja/ferramentas/top-10-enganos` | Top 10 mitos |

## Configuração

Edite `src/data/products.ts` para ajustar preços e número do WhatsApp (`WHATSAPP_NUMBER`).
